## 必须理解的区别

1. **视觉模型与逻辑载体不同。** 某些根 GLB 附带历史 Lua；当前逻辑以 `lua/` 和 `manifests/script-bindings.json` 为准。重复导入载体并自动运行旧脚本会引入重复逻辑。
2. **静态文件与运行时生成物不同。** 主舞台、NPC 聚光灯/底座、部分灯带由 Lua 生成，不能靠只导入 GLB 复原。对应代码与参数已包含并在清单中指明。
3. **这是原工程美术交接包。** 平台玩家服务、联机服务、原工程音频模块及编辑器内置基础形状仍由原工程提供；不是可单独启动的完整游戏工程。

## 快照与来源

`manifests/snapshot.json` 记录原场景摘要及采集范围；`manifests/assets.json` 记录每个文件的 SHA-256、源 URI、使用节点、网格和材质结构。GLB 中纹理/图片资源的统计按文件逐个列出，不能因为有些车没有贴图就推断全部道具没有贴图。

本包未提供对素材的新增再分发许可。平台资产 ID、原项目已有素材和用户提供的音频继续沿用其原有授权；请在约定的私有仓库内用于本项目协作。
